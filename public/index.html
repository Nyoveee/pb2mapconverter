Advanced Options
Enable movable sounds Specify whether movables should play the default PB2 sound when moved.
(Muting movables trigger actions are not supported as of now.)

Options
- Yes (all movables play a sound when moved)
- No (movables do not play sounds when moved)
Antigravity object type Specify whether to convert PB2 antigravity to Entity or Static Decoration.

In PB3, there is a dedicated antigravity entity that
- is animated
- has it's own hitbox
- is affected by gravity

Choosing Static Decoration would replace it with a static image, which resembles closer to PB2's behaviour.

My recommendation is to stick with entity and see if you tweak it's parameters to cater your map's needs. If you have mid-air antigravity however, static decoration maybe a better choice.

Options
- Entity (Antigravity becomes PB3 entity)
- Static Decoration (Antigravity becomes PB3 decoration)
Generate terrain Specify whether to generate background terrain for certain walls. (if unsure, stick to Yes)

In PB3, there is the option to generate background terrain. Certain walls like grasses and sands looks much nicer when terrain generation is turned on.

HOWEVER, there is a major bug in PB3 where some terrains may cause the map to be unplayable. Your browser may hang and get stucked forever when clicking 'Play as tester' or 'Preview Map'. If that's the case, you have to disable terrain generation.

(This bug is not related to me and is a PB3 bug, there's nothing I can do)

Options
- Yes (Terrain generation is turned on)
- No (Terrain generation is turned off)
Acid type Specify the liquid type for acids.

Options
- Toxic (Makes radioactive ambient sound when nearby, doesn't destroy body parts)
- Corrosive (Doesn't make ambient sound when nearby, destroy body parts)
Use Prosu's PB2 Module? Specify whether to convert the map in a way that is compatible with Prosu's PB2 MP module.

Multiplayer in PB3 work differently compared to PB2. There's no inbuilt supported for COOP and DM, and PB3 by default does not use the stats of the players in the map when joining in MP.

Prosu's MP module makes the PB2 map work with PB3 MP, allowing you to play the map straight away in multiplayer. This make the map works just like how PB2 works, with players in the map being used to determine the stats (skins, health, etc..) of joining players.

Options
- Yes (Convert map such that it's compatible with Prosu's PB2 MP module)
- No (Do not convert, keeps map simpler)

Results

1. Copy the generated PB3 map source code.
2. Go to your profile > creations > Make new Creation.
3. Right click on the creation you have created and select 'Edit Creation'
4. Go to 'File Contents' tab and paste the generated source code there.
